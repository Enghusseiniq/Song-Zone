# 🎵 Song Zone

مشغّل موسيقى أندرويد أصلي، خفيف وسريع — بلغة Java بالكامل، بدون AndroidX.

---

## 📖 نظرة عامة

Song Zone هو مشغّل موسيقى بسيط وسريع لنظام Android، مبني بلغة Java بشكل كامل، وبدون الاعتماد على AndroidX أو أي مكتبة خارجية ثقيلة. يعتمد فقط على Android SDK الأصلي و MediaPlayer و MediaStore، مما يجعله خفيفاً جداً وسريعاً في الأداء.

صُمم التطبيق ليكون بديلاً بسيطاً لمشغّلات الموسيقى الثقيلة، مع التركيز على الوظائف الأساسية التي يحتاجها المستخدم فعلاً.

---

## ✨ الميزات

| # | الميزة | الوصف |
|---|--------|-------|
| 1 | 🎧 قراءة تلقائية للأغاني | يقرأ كل ملفات الصوت من ذاكرة الهاتف عبر MediaStore |
| 2 | 🔍 بحث فوري | فلترة الأغاني أثناء الكتابة حسب العنوان أو الفنان أو الألبوم |
| 3 | 🎮 تحكم كامل | تشغيل، إيقاف مؤقت، التالي، السابق، شريط تقدم قابل للسحب |
| 4 | 🔁 أوضاع التكرار | مغلق / تكرار الكل / تكرار أغنية واحدة |
| 5 | 📢 تشغيل في الخلفية | يستمر التشغيل عند الخروج من التطبيق عبر Foreground Service |
| 6 | 🔔 إشعار تحكم دائم | أزرار السابق / تشغيل-إيقاف / التالي على شاشة القفل وشريط الإشعارات |
| 7 | ⚙️ شاشة إعدادات متكاملة | تخطي الصمت، Gapless، مؤقت النوم، إظهار المدة والرقم |
| 8 | 👨‍💻 شاشة "عن المطور" | معلومات التواصل وروابط التيليجرام والإيميل |
| 9 | 💾 حفظ التفضيلات | وضع التكرار والإعدادات تُحفظ بين الجلسات |
| 10 | 🎨 واجهة نظيفة | تصميم بسيط بألوان موحّدة، بدون تعقيد |
